# Web-opticon

**Modern surveillance for websites.**

A cutting-edge panopticon gets the prefered behavior by visitors on your website.

Hypotethical testimonies

- Are they watching?
- Can they see you for real?
- Are they recording this?

No way to be sure! Better behave!

## Example

HTML-file:
```
<web-opticon eyes="2" isglobal></web-opticon>
<script src="webOpticon.js"></script>
```
CSS-customization:
```
font-size: 3rem; /* sets eye-size */
--wo-eye-color-pupil: #f00;
--wo-eye-color-iris: #000;
--wo-eye-color-body: #fff;
--wo-eye-color-lids: #808080;
```
